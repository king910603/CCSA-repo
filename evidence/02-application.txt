
===== 2. Application functionality through the Nginx NodePort =====

$ curl -s -o /dev/null -w "%{http_code}" http://192.168.56.10:30080/
200
PASS: web UI served by NodePort at http://192.168.56.10:30080

$ curl -s -o /dev/null -w "%{http_code}" http://192.168.56.11:30080/
200
PASS: web UI served by NodePort at http://192.168.56.11:30080

$ POST http://192.168.56.10:30080/api/add_name {"name":"verify-1793182249"}
{"created_at":"2026-10-28 10:10:49","id":1,"name":"verify-1793182249"}


$ GET http://192.168.56.10:30080/api/get_names
{"names":[{"created_at":"2026-10-28 10:10:49","id":1,"name":"verify-1793182249"}]}

PASS: added name is returned by get_names

$ DELETE http://192.168.56.10:30080/api/remove_name {"name":"verify-1793182249"}
{"message":"Name removed successfully."}

PASS: deleted name is gone

$ POST http://192.168.56.10:30080/api/add_name {"name":"   "}
{"error":"Name is required."}
PASS: blank name is rejected
